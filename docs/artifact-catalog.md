## 2. 各表字段、校验与书稿对照

说明：**阻断** = 本步完成 / 复核通过 / 确认定版前必须消除；**提示** = 不阻断。

### 定战略责

**S1-01 战略简约六分法表 / 战略屋**（表 2-1 / 2-2，图 2-3 / 2-4）
- 字段：**六分法（P0 必做）**：目的（使命）、方向（愿景）、战略目标、策略选择、步骤举措、指标体系；**战略屋（P1 可选）**：价值观，一 / 三 / 五年经营目标，主要战场（名称、如何致胜、必赢之战），落地保障（组织、机制、人才）。使命、愿景两处共用。
- 校验：六分法六项全部必填（阻断，写“待补”不算填）；战略屋只有开始填了才检查，缺项为提示，不阻断。
- 导出：Excel、六分法 / 战略屋图片（PNG / SVG），计划书 Word 第一章附图以六分法为先。书中坑：假 / 空 / 坏共识，四个不是。

**M-MISSION 使命五要素萃取**（表 2-3 / 2-4）：核心用户、核心客户（是谁 / 痛点与核心需求）、独特差异化、核心竞争优势、事业的哲学意义、合成使命句。方法底稿，不阻断。

**M-VISION 愿景三法**：战略推导法、对标一流（选标 / 对标 / 定标）、引以为傲法、时间跨度（7—10 年）、愿景句。方法底稿。

**S1-02 战略地图**（图 2-8 / 2-9）
- 字段：目标（层面 financial / customer / process / learning、名称、说明）；连线（因果 cause 自下而上、协同 synergy）。
- 校验：至少一个目标、名称必填、因果必须自下而上（阻断）。导出：Excel。

**S1-03 企业战略、策略逻辑表**（表 2-7）
- 字段：战略（做不做 / 做什么）、其下策略（动词＋宾语，路径选填）、层级相对性说明；使命 / 愿景引用 S1-01。
- 校验：至少一条战略，战略与策略文本必填（阻断）。

**S1-04 IPOOC 指标设计表**（表 2-8 / 2-9，P1）
- 字段：每个关键策略一张：时间周期、责任部门；I / P / O 产出 / O 结果 / C 成本五环节各有要素拆解、指标名、计算公式、目标值、数据来源、考核频率；SMART 五项勾选。
- 校验：策略名必填、至少一个指标（阻断）；目标值、SMART 未过提示。

**S1-05 KPI 筛选评价表**（表 2-10 / 2-11，P1）
- 字段：候选指标（来源）、四维 1—5 分（战略相关性、可测量性、可控性、可激发性）、保留 / 剔除、理由。可从 IPOOC 带入。
- 校验：四维打完分、给出结论、至少保留一个（阻断）；超过 6 个提示。

**S1-06 战略 KPI 表**（表 2-10 / 2-11 筛选结果）
- 字段：战略主题、KPI、口径 / 计算公式、单位、数据来源、周期、责任部门。可从筛选结果带入。
- 校验：名称、口径、单位、来源、周期必填（阻断）；责任部门缺失、重名、超过 6 个提示。

**S1-07 战略 KPI 3—5 年年度分解表**（表 2-12 / 2-13）
- 字段：年度列（前三后一，可调）、每行 KPI 的各年值、基准值、标杆值、挑战值。可从 S1-06 带入。
- 校验：至少 3 个年度、首年必有值（阻断）；远年空值、无挑战值、KPI 表里有而此处无提示。

### 定目标责

**S2-03 第一步 定目标（目标区）**（表 3-4 / 3-5）
- 字段：往上看（回顾公司战略）、往回看（上期问题）、目标行（层面、目的、任务、衡量指标、指标值、单位，来源行）。可从 S1-07 本年度值带入。原来单独编号的 S2-03-T 已并入 S2-03（附录 B 无此编号），老数据在插件启动时自动合并。
- 校验：至少一个目标，任务 / 指标 / 指标值必填（阻断，提示前缀“定目标：”）。书中坑：只分数、把任务当目标。

**M-BUDGET 年度经营预算**（表 3-6）：预算编制说明、科目（营业收入、营业成本、销售 / 管理 / 研发费用、人员、投资预算、利润总额、经营性现金流，可增）的上年实际 / 本年预算 / 说明。方法底稿；无编制说明提示。

**S2-01 年度战略解码地图**（图 3-3、图 3-7～3-10，表 3-10）
- 字段：股东价值差距（年度目标 / 现状 / 差距）；财务、客户、内部流程、学习成长四层主题（类别、标题、衡量指标、指标值），财务主题挂年度目标，其余指向上层主题。
- 校验：主题必填且有支撑关系（阻断）。可一键导入 S2-03。

**S2-03 第二步 找路径**（图 3-1 / 3-2，表 3-9 / 3-10）
- 字段：按年度目标分组的路径节点（层级 1—4、路径、衡量指标、指标值、单位、层面、图 3-7 分组）。展示方式：思维导图（S2-02）、表格、按层面（表 3-10，可直接改）、横排表（表 3-9，只读预览），同一份数据。
- 校验：路径与指标必填、层级连贯、下级数值之和推得回上级（阻断）。书中要点：MECE、先 How 后 Who。

**S2-08 关键项目列表**（表 3-13 / 3-14）
- 字段：项目编号、名称、战略关联 / 主题、项目目标、起止时间（YYYY-MM）、关键节点、责任人、来源路径。按项目设置取一级或二级路径立项。
- 校验：名称、目标、起止、责任人必填（阻断）。

**S2-04 RACI 责任分解矩阵**（图 3-12，表 3-17 / 3-18）
- 字段：列（部门 / 岗位，可从组织带入）、行（关键项目或路径）、每格 R / A / C / I。
- 校验：每行 A 唯一、R ≥ 1（阻断）；同格 R+A、多 R、R 兼 C / I、多 C（> 2）、多 I（> 3）、R 超载、A 泛滥、全无 RA 提示。编辑器下方实时显示 表 3-18 验证优化表。

**S2-05 部门目标承接表**（表 3-20）：部门、角色（A / R）、目的、任务、衡量指标、指标值，可从 RACI 派生。校验：任务、指标、指标值必填（阻断）。

**S2-06 部门级目标路径系统图 / 表**（同表 3-9）：按承接项分组的部门路径，规则同 S2-03。

**S2-07 绩效计分卡**（表 3-21）：按部门分卡：关键任务、衡量指标、指标定义、保底值、力争值、权重、评分方法、数据来源；可从承接表派生。校验：每卡权重合计 100、指标与保底 / 力争值必填（阻断）。交付页可按部门导出。

### 定行动责

**S3-02 项目任务书（含 WBS）**（表 4-4）
- 字段：项目化判定（四问，≥ 2 为 P、1 为 S、0 为 R；成果导向重命名）；任务书：编号（年份＋职能简称＋P＋3 位，如 2026OPSP001 / 2024HR-P001）、名称、战略关联、优先级五因子（30 / 25 / 20 / 15 / 10）、目标、起止、范围内 / 外、交付物、关键节点、牵头部门与负责人、RACI、资源（FTE / 预算 / 物力）、Top3 风险（触发、应对）、关键假设、验收标准（结果 / 过程 / 关闭）；WBS 工作包（≤ 3 层：名称、交付物、完成定义、责任人、前置）。
- 校验：判定答完、P 类须有任务书、必填项、编号格式、WBS 完整且无循环（阻断）；风险数、范围外、优先级未打分提示。

**S3-05 计划实施推进表（含节点表）**（表 4-5 / 4-6）
- 字段：时间刻度（月 / 季）、按项目分组的节点（项目阶段、时间、名称、成果、验收标准、责任人、状态、前置节点）；可从任务书一级工作包导入。
- 校验：四要素必填、时间格式、前置节点不晚于本节点、无循环（阻断）；节点少于 3 个、模糊词（推进 / 加强 / 持续优化）、无责任人提示。
- 导出：节点表（表 4-5）与按月 / 季的推进表（表 4-6）两张。

**S3-06 项目资源匹配表**（表 4-8）：按项目的财务 / 人 / 信息化 / 物料四类：需求、存量、缺口、补齐方式、责任人、“无”、重大。校验：需求必填、重大缺口须有补齐方式与责任人（阻断）；缺类提示（填“无”即声明）。

**S3-07 公司级年度经营计划书**（公司级模板，八章）
- 企业录入：执行摘要、上年度总结、环境分析、风险、“不做什么”、指标字典补充说明。
- 自动汇总：1.2 本年度关键 KPI、1.3 关键项目清单；第四章 KPI 本年度目标 / 年度目标与路径 / 部门承接 / 计分卡；第五章项目与节点；第六章资源；第八章任务书合集、推进表合集、指标字典。
- 校验：四个必填章节（阻断）；“不做什么”提示。确认时 S3-02 / S3-05 / S3-06 须已复核通过并一起定版。导出 Word。

**S3-08 部门年度经营计划书**（部门级模板）：按 S2-05 的部门分册，录入章节同上（第七章为“三不做”清单）；自动汇总本部门的承接目标、部门路径、计分卡、牵头项目、节点、资源。导出 Word（每部门一份）。

## 3. 书稿对照结论

逐表对照方法论包中的模板（`tpl-*.md`）与 STEP-NOTES 后的修正已全部落地：RACI 补 表 3-18 七项验证；任务书编号接受书中带连字符的写法；节点表补“项目阶段”，导出补 表 4-6 版式；预算补编制说明与人员 / 投资科目；计划书第一章补 1.2 / 1.3；全部表加书中要点 / 坑 / 门禁。规格优先于书稿之处：资源四类（书为人 / 钱 / 物三类）、年度分解“前三后一”、环境盘点与经营目标责任书不在 V1。
