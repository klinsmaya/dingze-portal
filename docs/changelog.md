## 2026-10-16

### 插件 0.30.0 – 0.30.1 · 企业自建项目与从已有项目带入（甲方确认）

- **企业自建项目（按企业开关）**：
  - 运营在“企业与开通 › 项目与分派”顶部打开“允许企业管理员自建项目”，默认关闭。
  - 打开后，企业管理员在“本企业 › 项目”里点“新建项目”：填名称、年度，分派本企业账号（企业项目负责人、部门负责人、项目成员、只读成员），至少一位企业项目负责人。
  - 自建项目固定为“企业内训 · 自助”；需要陪跑时由运营改服务方式并分派咨询师。服务端同样拒绝咨询师角色、非本企业账号和开关关闭时的请求。
- **从已有项目带入（企业项目负责人手动触发）**：
  - 新项目“待办”页右上角“从已有项目带入”；企业管理员建好项目后直接打开。
  - 选本企业里自己也参与的来源项目，勾选要带的表：定版过的带定版内容，没定版的带最新草稿。
  - 带入后一律是草稿（进行中），照常本步完成、复核、定版；已本步完成、复核中、已定版的表不能带入。只带内容，不带批注和流转记录；版本历史记为“从已有项目带入”并注明来源。
- 注意：
  - 测试环境里所有企业的开关都是关闭的，需要试用时由运营逐家打开。
  - 北辰物流下有两个验证用的项目（“2028 年度战略落地（自建示例）”改名为“功能测试 · 自建项目”、“功能测试 · 带入目标”），已归档。

## 2026-10-15

### 插件 0.29.0 – 0.29.1 · 上下游连贯与训后优化（客户反馈）

**各表连贯、可承接**
- **“上游已变更”不再保存一次就消失**：
  - 表头提示旁有“看上游改了什么”，逐条列出上游哪里改了（改前 → 改后）。
  - 本表跟着改好后点“已核对”；已定版的表不受影响就点“已核对，保持定版”。
  - 上游正在修改时不能核对。核对记入审计。
- **一致性检查**（提示，不阻断；能自动改的带一键按钮）：
  - 年度目标 ↔ 3—5 年分解（S1-07）本年度值：“按 S1-07 更新”。改了衡量指标说法的视为有意换口径，不比数值；S1-07 本年度目标还没对应年度目标的也会提示。
  - RACI ↔ 关键项目、路径：缺 RACI 的关键项目，来源已删除或改名的行。
  - 部门承接 ↔ RACI：R 也要承接，来源行删除或角色变了要提示。
  - 计分卡 ↔ 部门承接：还没上卡的承接项。
  - 任务书 ↔ 关键项目、RACI：没做项目化判定的关键项目，时间、负责人不一致，牵头部门不是 RACI 的 A。
  - 推进表 ↔ 任务书：任务书已删除。
  - 资源表 ↔ 任务书：财务需求与预算金额不一致（只比金额，不比说法）。
- **计划书关键节点只取一处**：第 1.3 节的关键节点改为取推进表（S3-05）的节点，推进表还没有时才用任务书里写的。
- **战略地图 → 逻辑表 → 解码地图打通**：
  - 逻辑表（S1-03）和解码地图（S2-01）都能“从战略地图带入目标”，带入时记下来源目标。逻辑表的上游增加了战略地图。
  - IPOOC、筛选、战略 KPI、路径系统表改为按编号关联上游（策略、IPOOC 指标、候选指标、解码地图主题）。上游改名会提示“按上游改名”，删除会提示确认是否保留，不再因改名断链或重复带入。

**训后优化**
- **影响清单**：
  - 上游表头显示“下游 N 张待核对 · 影响清单”，列出直接下游和更下游的表、状态、是否待核对。
  - 已定版且待核对的可以勾选后一起解锁重开（写一次原因）。
  - 解锁重开的确认框里也先列出影响清单。
- **成果历史可查看**：
  - 每次定版标“第 N 次定版”，之后的版本标“优化第 N 轮”。
  - 每个版本可以“查看”，在填写页只读打开完整内容，可“和当前对比”“回到当前版本”。
  - 填写页表头新增“历史”。
- 表头提示的处理按钮（看上游改了什么、影响清单、不需要重开）直接放在提示旁边。

注意：
- 现有“上游已变更”的表，现在要点“已核对”才会消失。
- 演示数据上新检查发现了几处真实的不一致：启衡 2027 年度目标“充电量”写成 1200222（S1-07 是 12000），瀚川 2026 的加气站资源表仍是 6400 万元（任务书已压缩到 5400 万元）。按演示设计保留，没有改。

### 插件 0.28.0 · RACI 按书稿四条原则（客户反馈）

依据《自驱战略落地》第 3 章“横向到边”RACI 第二步（书第 148 页起）。

- **A 唯一**、**R 不可或缺**：照旧在“本步完成”和定版时强制。
- **R 不兼任 C / I**：原来只提示，现在改为必须改。
  - 录入时自动互斥：同一格勾 R 会去掉 C / I，勾 C 或 I 会去掉 R。
  - 已有数据如果还有 R 和 C / I 同格，会挡住“本步完成”和定版。
- **C / I 合理控制**、多个 R、同一部门兼 A 和 R：仍然只提示（书中没有禁止）。
- **书中方法（S2-04）**：按书四步改写，写明“ARCI 责任澄清会”和四条原则；完成检查分成四条，自助项目的自查清单同步。
- 注意：这一条超出需求规格 V1.2 第 12 页〔Q3〕的阻断范围（原来只阻断 A=1、R≥1），按客户 2026-10-15 意见调整。演示数据里现有的两张 RACI 表都没有冲突格。

### 插件 0.25.0 · 预验收意见中不需甲方拍板的优化

- 确认定版弹窗列出：
