### 2.2 甲方试用人员账号（B 线：试点企业真实走一遍）

甲方提供名单后当天开通，初始密码单独转交。名单每人写：姓名、登录名、手机或邮箱、角色；企业侧人员还要写所属企业和部门。

角色从下面选：

| 角色 | 能做什么 |
|---|---|
| 运营管理员 | 运营后台：企业开通、账号、训练营、看板、专家咨询受理。不进项目改表 |
| 咨询师 | 被分派到项目后，复核、退回、修订、批注 |
| 咨询管理员 | **运营管理员 + 咨询师 + 跨项目解锁重开**，还能开通咨询团队账号 |
| 企业管理员 | 维护本企业账号、组织与职责、邀请注册；可兼企业项目负责人 |
| 企业项目负责人 / 部门负责人 / 项目成员 / 只读成员 | 项目内的分工，见操作手册第二章 |

**一人兼咨询师和运营：** 开“咨询管理员”账号。它同时有运营后台和咨询师工作台，也能被指定为项目的主咨询师。不要给一个账号同时挂“运营管理员”和“咨询师”两个角色：门户一次只按一个角色显示菜单，也没有切换入口。咨询管理员还能对所在企业的任何项目解锁重开（必须写原因），开号时请确认这个人可以有这项权限。

### 路线一：企业第一次用（约 15 分钟）

1. **dz_zhang** 登录 → “我的项目”卡片上写着下一步 → 进入瀚川 2026。
2. 顶部阶段条看三个阶段进度；左栏点 S3-02 项目任务书，表头看退回原因、右栏看批注，点批注定位到格子。
3. 工具栏点“上下游”看上游改了什么、影响哪些表；点“书中方法”看本表的方法；点“怎么填”看填写说明。
4. 在批注上点“按批注修改”改一处 → “修改”页签看修改记录 → Ctrl + Z 撤销 → 表头“修订”对比上一版。
5. 右栏对数字咨询师说“这张表还缺什么”，看它给出的修改卡，确认或不采纳。
6. 切到瀚川 2027（顶栏项目切换）→ S1-01 按批注改战略目标。
7. “成果”菜单：先看交付成果，再看过程成果；导出 Word / Excel。

### 路线二：找路径和对话改表（约 15 分钟）

1. **dz_qian** → 启衡 2027 → S2-03 找路径。
2. 表 3-10 按层面看橙角“2.8 下级 2.6”，在校验行点一键修正，再 Ctrl + Z 撤回。
3. 切思维导图：看“年度目标 → 财务 → 路径”和合计胶囊；拖一个节点，松手前看预览。
4. 右栏说“把浙北制造业客户拆成绍兴 0.6 和湖州 0.4”，看修改卡和导图预览后确认。
5. S2-04 RACI 按批注补 A。
6. “资料”菜单：企业画像、组织与职责（可上传组织表让 AI 填入）、资料库。
7. “本企业”：账号、组织、邀请注册；若运营打开了“允许自建项目”，可新建项目并“从已有项目带入”定版成果。

### 路线三：咨询师复核（约 10 分钟）

1. **dz_chen** → 咨询师工作台看各项目待办。
2. 瀚川 2026 的 S3-02：复核通过或退回（退回必须写原因）。
3. 瀚川 2027 的 S1-02 / S1-06：复核。
4. 判断 S3-05～S3-08 的“上游已变更”：看影响清单，决定是否重开。
5. 在表上记一条“引导缺口”（书中方法没讲清的地方）。

### 路线四：只读与管理（约 10 分钟）

1. **dz_zhou / dz_he**：只能看和批注，编辑按钮是灰的并说明原因。
2. **dz_guan**：跨项目查看、解锁重开（须写原因）。
3. **dz_yun**：运营看板（按训练营批次筛选）→ 训练营：秋季第 2 期的营前准备、春季第 1 期的结营页 → 引导缺口评审 → 专家咨询受理分派 → 企业与开通（重置密码、允许自建项目开关）。

### B 线：试点企业从零走一遍

运营开通企业空间、企业管理员和项目（陪跑项目指定主咨询师）→ 企业管理员导入组织表、开通成员 → 上传企业简介等资料，确认企业画像 → 按左栏从 S1-01 开始逐表填写、本步完成、提交复核、确认定版 → 三阶段完成后在“成果”里交付年度经营计划书。

## 4. 问题与修改意见怎么提

用随附的《试用意见登记表》，一条问题一行。每条请写：

- **账号**：用哪个账号遇到的；
- **页面地址**：浏览器地址栏整段复制；
- **操作步骤**：做了什么、期望什么、实际看到什么；
- **截图**：能截就截，标出位置。

严重程度：

| 级别 | 含义 | 我方处理 |
|---|---|---|
| 阻断 | 某个流程走不下去，或数据错误 / 丢失 | 当天回复，尽快修复发布 |
| 影响使用 | 能绕过去，但别扭、易错、看不懂 | 归入下一批修改 |
| 建议 | 文案、排版、新想法 | 汇总后和甲方一起定取舍 |

节奏建议：甲方指定一位汇总人，每天收一次；我方每批修改发布后在[更新记录](changelog.md)写明改了什么、试用者要注意什么，并在登记表“状态 / 处理说明 / 版本”三栏逐条回复。

## 5. 已知限制

- 两人同时改同一张表，后保存的人会被提示刷新；还没有实时协同。
- 强制定版、强制退回、跳步例外在门户上没有按钮，需要时由我方处理。
- 扫描版 PDF 提取不到文字，请上传文字版或 Word。
- 没有邮件 / 短信通知，只有站内通知。
- 账号不能自己改密码，只能由管理员重置。
- 数字咨询师偶尔回复慢或答非所问，可重问一次；它的建议不会自动写入。

## 6. 需要甲方确认的事项

详见[试用安排](trial.md)第 3 节，登记表里也列了一份，可直接填意见。

1. **试用人员名单**（第 2.2 节格式）。
2. **试点企业资料**：企业全称、项目名称和年度、服务方式（陪跑 / 自助）、主咨询师、组织表、企业简介等。
3. **合规口径**：试点企业能否用真实资料、是否先取得企业同意、是否只用脱敏数据。确认前 B 线只用脱敏数据。
4. **反馈方式与节奏**：汇总人、渠道、频率。
5. **方法口径签认（8 项）**：增收方向术语对应、A / R 是否进计分卡、计分卡调整规则与评分锚点、KPI 数量是否硬限、S2-02 是否单列 P0、上游已变更时能否正式下载、规格第 15 / 17 页状态口径、书表勘误。
6. **待补的方法资料**：找路径诀窍与话术、计分卡调整意见、标准案例口径、路径层级上限、书中案例的使用授权。
7. **运营准备**：是否开邮件通知（需提供 SMTP）、开营名单（10/27 前）。
8. **演示数据**：正式试用前是否重置到初始状态。
9. **需求扩展取舍**：字段来源分层、路径贡献完整口径、资源按期间核算、视觉规范、易用性试点、咨询师案例库。
