# 运营与咨询师速查（我方版）

一页纸，够日常用。细节查[详细参考](user-guide.md)。

## 每天看一眼

- 「运营管理 › 运营看板」：哪些项目卡住了。
- 右上角铃铛：新试用企业注册、待复核的表。

## 新客户

- **客户自己注册的**：在「企业与开通」里带「自助试用」标签。系统已开好企业、管理员账号（手机号登录）和一个自助项目，不用我们做什么。
- **要转陪跑**：打开企业 ›「项目」，编辑项目，服务方式改成「陪跑」，分派主咨询师。
- **乱填或可疑的注册**：打开企业，点「停用企业」。
- **正式客户由我们开**：「企业与开通 › 开通企业」，填企业、管理员和项目。初始密码只显示一次，单独发给客户，不要发群里。
- **训练营**：用「训练营批次」批量开企业和账号。

## 复核一张表（陪跑项目）

1. 打开「咨询师工作台」，点待复核的表。
2. 看校验条有没有红色问题，看批注。
3. 没问题点「复核通过」；有问题点「退回修改」，写清要改什么。

## 已定版的表要改

- 主咨询师或企业项目负责人点「解锁重开」，写原因。
- 下游的表会提示「上游已变更」，由企业核对后点「已核对」。

## 客户常问

| 问题 | 怎么答 |
|---|---|
| 忘记密码 | 「企业与开通」里找到人，点「重置密码」。新密码只显示一次，单独发给他。 |
| 表打不开 | 上一张还没点「本步完成」。 |
| 不知道怎么填 | 点表上的「看示例」，或左侧菜单「示例项目」；也可以直接问数字咨询师。 |
| 能不能传真实资料 | 试用期请用脱敏资料。资料和对话会发给大模型服务。 |
| 数字咨询师改了我的表？ | 不会。它只给修改卡，客户点确认才写入。 |

## 给客户的说明

直接发[三分钟上手](quick-start.md)，或让客户看门户左侧菜单的「使用指南」。
