# 三分钟上手（客户版）

做完下面五步，你会拿到公司和部门两级的年度经营计划书。每一步右边都有数字咨询师，不会填就问它。

网址：https://ziqu.aihupo.cn/x/dingze/

## 1. 注册

- 打开网站，点「免费试用」。
- 填企业名称、姓名、手机号、密码，勾选试用说明，点「开始试用」。
- 系统自动登录，进入你的项目。以后用手机号登录。
- 要叫同事一起做：左侧「本企业 › 邀请注册」点「新建邀请码」，把链接发给同事，他们凭码注册就直接进项目。拿到邀请码的同事直接打开链接注册即可。

## 2. 上传资料

- 点顶栏「资料」，上传企业简介、组织架构、上年经营复盘。Word、PDF、Excel 都可以。
- 在「组织与职责」里填好部门和负责人。
- 点右边对话里的「从资料整理企业画像」，看一遍，点确认。
- 试用期间请用脱敏资料。资料不全也可以先往下走。

## 3. 战略解码

- 点顶栏「战略解码」，从第一张表开始填。
- 想看别人怎么填，点表上的「看示例」。
- 数字咨询师给的是修改卡，你点「确认」才会写进表里。记得保存。
- 填完点「本步完成」，再做「自查复核」，最后「确认定版」。下一张表会自动打开。

## 4. 目标分解

- 战略解码的必做表都定版后开启。
- 定年度目标，找到实现路径，把关键项目和指标分到部门。

## 5. 计划制定

- 目标分解定版后开启。
- 写项目任务书、推进表和资源表，最后生成公司和部门的年度经营计划书。
- 在顶栏「成果」里下载 Word 和 Excel。

## 常见问题

- **表上有锁、打不开**：上一张还没完成。先把上一张点「本步完成」。
- **提示「上游已变更」**：前面的表改过了。点开看改了什么，跟着改好，再点「已核对」。
- **数字咨询师回得慢**：一般要 10～30 秒，稍等一下。
- **想请人工咨询师陪跑，或忘记密码**：联系我们。
