# 三分钟上手（客户版）

网址：https://ziqu.aihupo.cn/x/dingze/

## 1. 注册

- 点「免费试用」，填企业名称、姓名、手机号、密码。
- 叫同事一起做：在「本企业 › 邀请注册」新建邀请码，把链接发给同事。

## 2. 上传资料

- 点「资料」，上传企业简介、组织架构、上年经营复盘。
- 填好部门和负责人，点「从资料整理企业画像」，看一遍后确认。

## 3. 战略解码

- 从第一张表开始填。不会填，点「看示例」或问右边的数字咨询师。
- 填完点「本步完成」→「自查复核」→「确认定版」，下一张表自动打开。

## 4. 目标分解

- 战略解码全部定版后开启。定年度目标，找到路径，把关键项目和指标分到部门。

## 5. 计划制定

- 目标分解定版后开启。写任务书、推进表、资源表，生成年度经营计划书。
- 在「成果」里下载 Word 和 Excel。

## 常见问题

- **表上有锁**：上一张还没点「本步完成」。
- **提示「上游已变更」**：前面的表改过了，点开看改了什么，改好后点「已核对」。
- **数字咨询师回得慢**：一般 10～30 秒。
- **想请人工咨询师陪跑，或忘记密码**：联系我们。
