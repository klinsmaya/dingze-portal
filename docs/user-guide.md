# 使用说明

自驱战略 · 定三责平台把《自驱战略》书中的三张检查表变成一步一步的在线工作：**定战略责 → 定目标责 → 定行动责**。每一步都有一张成果表，企业填写、咨询师复核、企业确认后定版；下游表格引用上游的定版内容，上游一改，下游会提示“上游已变更”。

入口：`https://<域名>/x/dingze/`，用分配的账号登录。平台不开放自助注册；忘记密码点登录页的“忘记密码”，按提示联系本企业管理员或平台运营重置。打不开某个项目时，页面上有“回我的项目”。

---

## 一、企业成员

### 1. 进入项目

登录后进入“我的项目”。每张项目卡片直接写着**下一步要做什么**（例如“去定版：公司级年度目标 · 路径”“改退回的表：项目任务书”），点卡片就到那张表。

企业成员在项目顶部只有四个入口：

| 入口 | 用途 |
|---|---|
| 今天要做的 | 最上面是「项目启动」（见下），然后是最要紧的一件事（大按钮），以及正在流转的表和它们的状态：顾问在审、已退回（带原因）、待你定版、上游有改动 |
| 填写 | 逐表填写成果（主要工作区域） |
| 资料 | 资料库、已确认成果、组织与职责、企业画像（见第 7 节） |
| 成果 | 两个页签：**成果清单**（每张表的状态、版本、历史和对比）和**交付包**（计划书 Word、Excel、图片、导出记录）（见第 5 节） |

咨询师和管理员看到完整导航：工作台、咨询工作区、资料与画像、成果、专家咨询。

**训练营和企业内训对企业是同一套界面**，区别只在咨询机构的组织方式。

**项目启动**：开始填表前要准备好的三件事，在“今天要做的”最上面逐项显示还缺什么、该谁去做：
1. **组织与职责**：组织里建好了部门，项目里的企业成员都归到了部门。没有在系统里指定负责人的部门会单独提一句，但不算没准备好。
2. **资料与画像**：至少有一份资料，企业画像里至少一条经企业项目负责人确认。
3. **团队与角色**：有企业项目负责人；有部门的话，还要有部门负责人参与。

三项都齐了，这里收成一行“项目启动已就绪”。没齐也可以先填表。

表名一律先写人话（如“责任分工矩阵”），书里的名称和编号（《RACI 责任分解矩阵》· S2-04 · 表 3-17）用小字跟在后面。

### 2. 在“填写”里改表

填写页是一整屏的工作台，页面本身不滚动，只有中间的表格 / 导图区域滚动，右侧对话输入框始终在底部：

- **顶栏**：当前步骤名和项目名，后面是这一步的子步骤（例如找路径的“股东价值差距 → … → 导入表 3-10”，做完的打 ✓）；右侧是 **白天 / 黑夜 / 自动** 三档主题、项目成员头像、通知铃铛、右栏开关。
- **左栏“项目路线”**：工作任务 → 实施步骤 → 子步骤，当前步骤展开；顶部是“今天要做的 / 工作台”返回入口和资料、导出等快捷入口；标题下拉可切换三个阶段；底部列出“本步产出 · 同一份数据”。窗口窄于 1280 像素时自动收成一列图标，点 » 展开。前一步“本步完成”后，后一步才解锁（锁形图标）；上一阶段 P0 成果全部定版后，下一阶段才开启。
- **中间三行表头**：第一行是面包屑和状态（已退回 · 查看原因、已定版 · 说明、上游已变更、协作中），右侧是保存状态——“已保存 HH:MM · vN”，有改动时变成“有 N 处未保存 · 保存”按钮（也可 Ctrl / ⌘ + S）；第二行是《表名》和编号、**思维导图 / 表格** 切换、版式、修订开关、批注、导出、本步完成等动作；第三行是常驻的调整工具条（撤销 / 重做、下级、同级、升降级、上下移、移动到…、拆分、合并、批注、圈选、删除、缩放、小地图、快捷键），作用于选中的节点或行。
- **右栏四个页签**：对话（数字咨询师）、批注、修改、书中方法。窗口窄于 1100 像素时右栏变成抽屉，用顶栏右侧按钮打开。
- 表头写着这张表现在的状态：进行中、**顾问在审，审完会通知你**、**已退回修改：原因**、**顾问已审过，待你定版**、已定版。
- 很多表有“带入 / 导入”按钮，可以从上游表直接带入，不用重抄。
- 下方的校验条列出必须改的问题（红色）和建议（黄色）。红色问题没改完，不能点“本步完成”。**点问题可直接跳到对应的行或格**。
- 最底下的状态条随时显示：推得回来几处 / 几处推不回来、几处必须改、几条未解决批注、修订开关、当前选中；按 **?** 打开全部快捷键。

#### 改表的四种方式（所有表通用）

| 方式 | 怎么做 | 结果 |
|---|---|---|
| 直接改 | 表格像 Excel：点格子（或选中后直接打字 / Enter / F2）就改，Enter 保存、Tab 下一格、Esc 取消；思维导图里双击节点或按 F2，路径、衡量指标、指标值三项一起改，改动中的原值以删除线淡显 | 立刻生效，改过的地方左侧出现青色竖线 |
| 调结构 | 顶部工具条，或悬停一行出现的行工具条（同级、下级、升降级、上下移、批注、删除、⋯）；思维导图里可以**拖到别的节点上**换上级，或拖到两条之间的“放到这里”调整顺序；表格里按住行左侧的拖动柄拖整行；表 3-10 还可以“从 Excel 粘贴”整块路径 | 拖动时顶部提示“Esc 取消”，松手前右侧“松开后会这样”说明会成为第几级第几条、合计怎么变、几条下级一起移动；如果会让原来的上级推不回来，默认同时把上级改成新合计（松开时按住 Shift 则只移动）；删除后 8 秒内可撤销 |
| 批注 | 在格子或节点上**右键“插入批注”**，或选中后按 Ctrl + Alt + M，就在那一处写；输入 @ 弹出成员名单（会收到通知），@数字咨询师 会请它给修改建议；Ctrl + Enter 发送。工具条“**圈选**”可以点选多处一起批注 | 画布上钉一个带编号的紫色水滴（①②③…），圈选的批注画一圈紫色虚线框；还没发出的批注在批注页签里显示为“草稿” |
| 对话 | 右栏“对话”：跟数字咨询师说想怎么改 | 它只出**修改建议卡**：改哪几处（修改、拆分、删除、移动，按 1、2、3 编号）、合计推不推得回来、必须改的问题会从几处变成几处；同时导图 / 表格切到预览，琥珀色虚线和序号对应卡片上的条目。点“确认修改”才写入草稿，“改一下”继续商量，“不采纳”丢弃。数字咨询师不会直接改你写的内容 |

- **撤销 / 重做**：工具栏 ↶ ↷，或 Ctrl / ⌘ + Z、Ctrl / ⌘ + Shift + Z。一次修改（连续敲同一格算一次、一次拖动算一次）撤销一步；保存后仍可以继续撤销本次打开以来的修改。
- **修改**页签（右栏第三个）是修改记录，按天分组：几点、谁、从哪里改（直接改 / 调结构 / 对话 / 粘贴 / 撤销），关联了哪条批注；可按人、按来源筛选，可导出 CSV，每条都能“定位”和“撤销”。保存时这些记录随版本一起存下。
- **修订**（表头“修订”开关、修改页签顶部开关，或 Ctrl / ⌘ + Shift + E）：选一个历史版本和当前对比。格子里原值删除线、新值下划线，旁边是修改人的头像；新增的行带绿色；删掉的行留在原表下面（删除线），可一键“恢复”；表底汇总“对比 vN：改几处 · 增几行 · 删几行 · 几人”。关着时只标出“上次保存之后改过的”地方。
- **批注页签**：全部 / 未解决 / @我 筛选，按位置或按时间排序；每条批注下可以直接回复（同样可 @），已解决的折叠在最下面。**按批注修改**：点紫色“按批注修改”会定位到那一处，之后的修改都关联到这条批注，保存后自动回复“已按批注修改：……”，由提批注的人决定是否解决；点旁边的数字咨询师按钮，会把批注原文带到对话里，让它出修改建议卡（确认后同样附在这条批注下）。
- 改完记得点“保存”（或 Ctrl / ⌘ + S）。每次保存生成一个新版本；有未保存的修改时离开页面会先提醒。
- 右栏“数字咨询师”第一次打开时给出三句可以直接点的开头：“帮我看这张表缺什么”“解释这一格”（会带上你刚点过的格子）“建议怎么填”。项目里只有这一个 AI 入口，右下角不再有浮动球。
- 右栏顶部“书中方法”列出这张表在书里的要点、常见的坑和定版门禁。

#### 思维导图 / 表格

找路径（S2-01 年度战略解码地图、S2-03 公司级路径系统表、S2-06 部门路径）和项目任务书的 WBS 都有两种展示，**是同一份数据**，改一边另一边马上跟着变；系统记住你上次用的方式。

- **思维导图**：从左到右的树，适合共创、发散、调结构。路径系统和解码地图按书的结构画：**年度目标 → 四个层面（财务 / 客户 / 内部流程 / 学习与成长）→ 路径**，还没开始的层面显示为虚线“子步骤 N · 待开始”。有下级的节点下方挂一个合计胶囊（如“700 + 300 = 1000”，推得回来绿色，推不回来橙色并在节点右上角标橙角）；每组路径末尾有虚线“+ 一级路径”。点选节点出现工具条（下级 / 同级 / 批注 / 移动到… / ⋯）；Tab 新增下级、Enter 新增同级、Alt + Shift + 方向键调层级和顺序、Shift + F10 移动到…、Delete 删除，← → 折叠展开。缩放组里的“小地图”显示全图缩略，点哪里跳到哪里。
- **表格**：适合逐格核数字、整理定稿。S2-03 默认“按层面”（书中表 3-10）：表头两行（一级 / 二级 / 三级路径 × 路径 · 衡量指标 · 指标值），年度目标作为表内第一行，左侧层面列带图标，可收起成一行摘要；下级合计推不回来的上级指标值格标橙角并写“下级 N”；每个层面下面是校验行，列出“1000 = 700 + 300”等核对，推不回来时给出一键修正（“把『某条』改为 X”“把上级改为 Y”“先放着”）；叶子行后面有“+ 分解三级路径”。工具条右侧可勾“四级列”。“横排表”是表 3-9，只读预览，和导出 Excel 一致。
- 找路径的五个子步骤在表头一条导航里：子步骤 1–4（股东价值差距、客户价值主张、关键价值创造流程、战略资产准备度）在 S2-01，子步骤 5（导入路径系统表）在 S2-03。
- **图 3-7 参考卡**：浮在导图右上角，可收起。一级路径按“增长战略（增加收入机会、提高客户价值）/ 生产率战略”两组想；已经用过的项打勾并注明“第 N 条”，点一项就加一个一级路径（S2-01 里加一个对应类别的财务主题）。
- 四层泳道图保留为 S2-01 的“解码地图版式（图 3-3）”，只读，用于汇报。

### 3. 本步完成 → 复核 → 确认

第一次点“本步完成”时，系统会先用一个小窗说明后面会发生什么（顾问复核 → 企业定版 → 锁定后只能请主咨询师解锁重开），之后不再提示。

1. 企业填写完毕，由企业项目负责人或部门负责人点 **本步完成**。
2. 咨询师、企业项目负责人或部门负责人**提交复核**，主咨询师**复核通过**或**退回修改**（退回必须写原因）。
3. 复核通过后，**企业项目负责人**点 **确认**，成果**定版**。定版后只读，如需修改，由主咨询师“解锁重开”。

> 只有企业项目负责人可以确认定版；企业管理员身份本身不带确认权。

不同意但愿意执行的意见，可以在成果下方“团队异议（反对但承诺执行）”里记录。

### 4. 年度经营计划书

定行动责的最后两张是公司级和部门级年度经营计划书。“企业录入”的章节由企业填写；“同源 · 自动汇总”的章节直接引用已定版的成果，不需要也不能重写。

公司级计划书确认时，它引用的《项目任务书》《计划实施推进表》《项目资源匹配表》必须已复核通过，确认后四张表**一起定版**。

### 5. 成果与导出

- 「成果」一个入口，两个页签：“成果清单”看每张表的状态、版本、历史和对比；“交付包”最上面是**下载计划书 Word**（公司级和部门级），Excel 和图片在“其他表格与图片”里。原来的“成果与定版”“导出 / 交付”链接会自动跳到这里。
- 表一定版，就同时出现在「资料 › 已确认成果」里，数字咨询师和专家咨询按定版内容引用。
- 成果页右上角“导出 Excel / 导出 Word”导出最近一次**保存**的版本。
- S1-01（战略屋 / 六分法）和 S1-02（战略地图）还有“导出图片”：PNG 适合汇报和文档，SVG 是矢量图，可再编辑。
- 公司级年度经营计划书第一章自动附图 1-1 战略屋（或六分法表）和图 1-2 战略地图，Word 中为矢量图（老版本 Word 显示清晰位图）。
- “交付包”导出的是**定版版本**；尚未定版的导出文件会标“草稿”。
- 所有导出都记录在“成果 › 交付包 › 导出记录”。

### 6. 通知

右上角铃铛显示站内通知：待复核、待确认、退回、定版、重开、上游已变更、加入项目、批注与 @、专家咨询进展。点通知直达对应成果、批注或咨询。

### 7. 资料、组织与企业画像

「资料」页从上到下：资料库、已确认成果、组织与职责、企业画像，顶部有目录可以跳转。

- **在哪导入资料**：「资料 › 资料库」上传文件或粘贴文字，这是唯一的存放处。填表时也可以在两处顺手放进资料库：
  - 右栏对话的 ⋯ 菜单 → “上传资料…”：文件存进资料库，同时在输入框里写好“请参考《…》”。
  - 对话的 ⋯ 菜单 → “引用资料”：从已有资料里挑一份让数字咨询师参考。
- **在哪查看资料**：「资料」页；填表时左栏下方“参考资料”列出最近的资料，点开在右侧预览，不离开当前表。
- **组织与职责**：只读展示企业的部门层级、各部门负责人，以及项目成员归属哪个部门。
  - 怎么修改：企业管理员（或运营）在「本企业 › 组织部门」维护：部门的名称、上级、负责人（有账号选账号，没有账号填姓名）、**职责**；也可以“从 Excel 粘贴”整张组织表（名称、上级、类型、负责人、职责），预览后一次导入，同名部门更新。同一页下方“成员所属部门”给每个企业成员选部门，对本企业所有项目一起生效。
  - 哪里会用到：责任分工矩阵（S2-04）的责任者列取自这里的部门；部门目标承接（S2-05）和部门计划书（S3-08）按承接的部门展开。
  - 组织变了怎么办：表定版后保留当时的部门。之后组织有增删、改名、换负责人、改职责，已定版的部门表（S2-04 / S2-05 / S2-06 / S2-07 / S3-08）表头会出现“组织已变更 · 看变化”，主咨询师和企业项目负责人会收到通知。主咨询师判断：需要按新组织调整就“解锁重开”；不影响就点“不需要重开”并写一句理由（记入审计）。重开或重新定版后提示自动消失。
  - 责任分工矩阵的表头在部门名下面用小字显示部门职责，定 A、R 时对照。
- **资料库**：上传经营总结、行业报告、经营数据表等（Word docx、PDF、Excel xlsx / xls / xlsm / xlsb / ods、txt / md / csv，单个不超过 20MB），平台在浏览器里提取文字后保存；也可以直接粘贴文字。Excel 按工作表逐行读取，公式取计算结果、日期和百分比按表格里的显示；业务系统导出的网页格式 .xls 也能读。数字咨询师会检索资料并注明出处。
- **企业画像**：按“事实 / 假设 / 未知 / 待补”分类记录企业情况，每条注明来源。可以让数字咨询师根据资料起草画像条目（需确认写入，起草的条目一律为草稿）。
- 画像条目由咨询师**复核**、企业项目负责人**确认**；他人修改已复核或已确认的条目，会回到草稿。两人同时编辑时，后保存的一方会被提示刷新。
- 画像摘要会随页面上下文提供给各阶段的数字咨询师。

### 8. 专家咨询

遇到方法流程解决不了的关键分歧（战略取舍、路径合理性、责任冲突、资源约束），在项目的“专家咨询”页**申请专家咨询**：写清议题和问题，并勾选要授权专家查阅的**已定版成果**（以申请时的定版为准）。

流程：咨询管理员受理并分派专家 → 专家预约沟通时间与方式 → 专家写纪要和意见 → 申请人或企业项目负责人确认关闭。出意见前申请人可以撤回。每一步都会通知相关人。年度经营计划质询在线下进行，不在平台内申请。

## 二、咨询师

- 登录后进入**咨询师工作台**：跨企业汇总待复核、待提交复核、待企业确认、上游已变更和待跟进的成果，可按企业和阶段筛选。
- 复核：打开成果 → 看校验结果；右栏“修改”页签打开**修订**，选上一版对比，逐条看修改记录（谁、从哪里改、关联哪条批注）→ 复核通过或退回（写原因）。也可以在“成果与定版 → 历史 → 版本对比”里看整版差异。
- 复核中的表咨询师可以直接改（修订），修改同样记入修改记录，企业能看到。
- 解锁重开：已定版成果需要修改时，由主咨询师“解锁重开”并写明原因；下游表格会标“上游已变更”，企业核对后保存一次即可消除。重开后未改动又定版，下游提示会自动消失。
- 开例外：确有需要跳过解锁顺序时，主咨询师可为某一步“开例外”，操作会写入审计记录。
- **成果与定版**页的“AI 初稿 → 定版”一列，显示数字咨询师给出的最后一版初稿与最终定版之间的差异，用于方法和规则改进。
- **记录引导缺口**：发现数字咨询师没引导到、引导错了，或校验口径与书不符时，在工作区右侧数字咨询师下方点“记录引导缺口”，写明缺口与期望的引导（对话摘录请去掉企业敏感信息）。评审结果会通知你。
- **企业画像**：在“资料与画像”页复核画像条目。
- **专家咨询**：被分派为专家时会收到通知；在侧栏“专家咨询”打开申请，查阅授权的定版成果，预约沟通、填写纪要和意见。

## 三、运营管理员 / 咨询管理员

侧栏“运营管理”：

| 页面 | 用途 |
|---|---|
| 运营看板（默认页） | 各企业项目的阶段进度（P0 定版数）、待复核 / 待确认 / 待更新 / 未解决批注积压、数字咨询师近 30 天与累计的对话轮次和 Token 用量（只记录不计费），可按企业和“只看有待办”筛选 |
| 企业与开通 | 开通企业（自动建空间和企业管理员账号）、停用 / 启用企业、维护企业成员和组织部门、新建项目、分派项目成员与项目角色 |
| 咨询团队 | 创建咨询师、咨询管理员、运营管理员账号，重置密码 |
| 方法与规则包 | “规则包”页签：成果目录与数字咨询师（只读）；“引导缺口”页签：评审咨询师记录的缺口——采纳 / 不采纳（须写理由）→ 改写规则并随新版插件发布后标“已发布”（填版本号），每次评审通知记录人 |

侧栏“专家咨询”：受理新申请并分派本企业空间里的咨询师为专家（咨询师需先是该企业成员），可改派；也可代为预约和填写意见。

要点：

- 一个企业对应一个独立空间，企业之间的项目、成果、通知、导出互不可见。
- 停用企业后，该企业成员立即无法打开项目（运营与咨询管理员仍可查看）。
- 新账号的初始密码只在创建时显示一次，请通过安全渠道转交，并提醒首次登录后修改。
- 企业管理员可在“本企业”里维护本企业成员、组织部门（含职责、无账号负责人、Excel 导入）和成员所属部门。

## 四、角色速查

| 项目角色 | 能做什么 |
|---|---|
| 企业项目负责人 | 填写、本步完成、提交复核、确认定版、待确认时退回 |
| 部门负责人 | 填写、本步完成、提交复核 |
| 项目成员 | 填写 |
| 只读成员 | 查看、批注 |
| 主咨询师 | 修订、提交复核、复核通过 / 退回、解锁重开、开例外 |
| 协作咨询师 | 修订、提交复核 |
| 咨询管理员（系统角色） | 解锁重开、开例外、强制定版、强制退回（均需写原因）；受理专家咨询、评审引导缺口 |
| 运营管理员（系统角色） | 运营管理全部页面，含运营看板、引导缺口评审、专家咨询受理 |

画像条目：咨询师复核、企业项目负责人确认。批注：项目里所有人（含只读成员）都可以发表和回复；作者、企业项目负责人、主咨询师可标记解决。只读成员不能改内容。
