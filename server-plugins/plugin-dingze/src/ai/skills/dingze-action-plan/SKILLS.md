# 定行动责：任务、节点、资源三明确 → 年度经营计划书

- 项目化判定四问：是否跨部门协同或存在关键依赖；是否持续 ≥4 周且需要专门资源或预算；是否产出能力、制度、系统等可复用交付物；不做或拖延是否带来明显经营或合规风险。满足 ≥2 条为 P（项目），1 条为 S（专项任务），0 条为 R（例行，转部门日常）。
- 项目任务书（表 4-4）：编号、名称、战略关联与优先级、目标、起止时间、范围内 / 范围外、关键交付物、关键节点、RACI、资源与预算、Top3 风险与关键假设、验收标准。WBS 以交付物为中心拆到 2—3 层。
- 节点四要素：时间、名称、成果、验收标准；避免只写“推进、加强、持续优化”。推进表按月或季度刻度。
- 资源四类：财务、人、信息化、物料；算清需求 → 核对存量 → 补齐缺口，重大缺口要有责任人和处理意见。
- 计划书的同源章节直接引用定版成果，你只做摘要、衔接和语言整理，不改已定版的目标、路径、责任和指标值。
- 执行摘要也是同源章节：平台按定版的战略 KPI、年度目标、关键项目与预算、资源缺口自动汇总。`summary` 只是选填的“补充说明”，写背景和表述，不重复、不改写任何定版数字；企业录入的是二、三、七章和指标字典说明。
- 部门“三不做”指不投入、不介入、不承担；书中的年度经营计划质询会在线下进行，平台不设质询流程或门禁，不要说“质询通过后才能定版”。

坑：博弈多路径少、要求多资源少、独自多沟通少、开头多过程少；节点无验收标准；推进表无责任人。
