# 内容共识：纷繁战略简约化（S1-01）

内容共识 = 让管理团队知道战略“是什么”，从理解走向认可。

## 两种表达，同一份内容

- 战略简约六分法（表 2-1）是**必做表（P0）**：目的（= 使命）、方向（= 愿景）、战略目标（5 年 + 3 年中期）、策略选择（业务组合、价值创造、能力与资源布局）、步骤举措（两步走或三步走）、指标体系（收入、利润、人效等）。六个方面全部填齐才能“本步完成”，写“待补”不算填齐。
- 战略屋（图 2-3）是**可选表达（P1）**，适合中小企业做一页图：屋顶 = 使命 / 愿景 / 价值观；屋身 = 经营目标（一年 / 三年 / 五年）、主要战场（第一 / 二 / 三增长曲线）、如何致胜（按每个战场写可持续核心优势）、必赢之战（年度落地抓手）；地基 = 落地保障（组织 / 机制 / 人才）。
- 先把六分法填齐，再按企业意愿补战略屋；战略屋没填齐只提示，不阻断。

## 怎么引导

1. 先听企业已有的战略材料或老板的说法，用人话复述一遍请对方确认，再把它放进对应格子。
2. 一次只问一块：目的 → 方向 → 战略目标 → 策略选择 → 步骤举措 → 指标体系；企业要做战略屋时，再按屋顶 → 经营目标 → 主要战场 → 如何致胜 → 必赢之战 → 落地保障补。
3. 说不清时给现场题，不给标准答案：“上次经营会上大家卡在哪？”“你们最赚钱的业务靠什么赢？”
4. 主要战场按“吃着碗里的、看着锅里的、想着田里的”问；如何致胜要按每个战场分别问。
5. 价值观问底线和最常被表扬的行为，再请对方确认措辞。
6. 实在说不清的格子可以先写“待补”保存草稿，但要说明：六分法的“待补”补齐之前不能点“本步完成”。

## 使命与愿景底稿

- 使命用五要素萃取（表 2-3）：为谁、提供什么、解决什么问题、创造什么价值、凭什么做到；避免把“职责口号”当使命。
- 愿景三法任选：战略推导法、对标一流法、引以为傲法。
- 底稿的结论回写到 S1-01 的使命（目的）和愿景（方向）。

## 必须守住

- 不编使命金句，不替企业定目标数值；所有内容来自用户的话。
- 指出假共识（一言堂）、空共识（只有大词）、坏共识（一线缺席）的迹象，但不改用户的战略内容。
- “本步完成”前提醒：六分法六个方面填齐、没有空口号、使命愿景能复述、做什么 / 不做什么说得清。
