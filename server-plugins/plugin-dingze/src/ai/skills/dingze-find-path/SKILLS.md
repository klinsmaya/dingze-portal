# 路径支撑，确保结果必赢

- 完整目标 = 目的 + 任务 + 目标值；年度目标来自“往上看”（使命愿景战略、战略 KPI 年度分解）和“往回看”（上期问题与解法），不得由你补造。
- 目标不可谈，路径与资源放开谈。先 How 后 Who：先找路径，不填部门和人名。
- 路径要 MECE、分得下去、推得回来：下级合计要能推回上级；硬指标要落到客户、产品、渠道、区域、项目等具体路径。标准图放到四级。

## 找路径引导规则包（解码地图四个层面）

用户能自己说出路径时不打断；说不出时才按下面逐级追问：

- 财务 · 股东价值差距（图 3-7）：增收 7 条——公司内部四个方向：产品、业务、区域、经营模式；客户三个方向：开发新客户、老客户转介绍、提高单客户价值。用户都说“没有”时依次追问：有没有新产品、新业务？是不是真的没有收入机会？客户有没有新需求？基于新需求应该做产品还是做业务？降本：改善成本结构、减少现金支出等。
- 客户 · 客户价值主张（图 3-8）：产品和服务属性（价格、质量、可用性、选择、功能）、关系（服务、合作）、形象（品牌），要与财务增长目标协调。
- 内部流程 · 关键价值创造流程（图 3-9）：运营流程、客户流程、创新流程、品牌传播流程，逐类问今年有没有变化，只取影响最大的少数几个。
- 学习与成长 · 战略资产准备度（图 3-10）：人力、数字化、企业文化 / 领导力 / 团队，逐方面问今年有什么新任务。

用户顺口提到但不属于当前层的内容先记下，分解到相关路径时带出来请他确认。每条路径都要有衡量指标和指标值。

## 分支式引导（专项推进会 09-22：企业最难的是不会找路径）

1. 先复述：本期目标、基期、缺口和约束各一句，问“我理解得对吗”。缺口算不出来时先问基期，不要跳过。
2. 每轮只聚焦一个判断：给两三个最可能适合这家企业的方向，并说为什么问这个；不要一次列满七条。
3. 用户回答后追问证据（客户名单、合同、渠道、产能、往年数据），有证据才写成路径；没有就标“待证实”。
4. “不知道”：换成现场题（“去年新增的客户主要是谁带来的？”），或请他去查哪份资料、问哪个部门，把这一项标为待补，先走下一项；不要替他给答案。
5. 连续否定新产品、新业务、新区域时，转向老客户：流失、未满足的需求、转化率、单客价值；再看降本（成本结构、现金支出、资产效率）。仍没有证据就如实保留缺口，告诉用户“目前能推回的是 X，还差 Y”。
6. 已经被否定的方向不要再写回计划；用户改口时以最新回答为准，并复述一次。
7. 来源冲突（旧资料和口述不一致）：两个值和出处都列出来，请用户选本期口径。

## 贡献核算

- 每条路径说明它贡献的口径：指标、单位、期间、基准和增量；不同口径（如公里和覆盖率、客户数和售气量）共同支撑，不能相加。
- 跨层要用桥接说清楚：如 新增售气量 = 新增客户数 × 户均用量；收入 = 量 × 单价。
- 去重：同一批客户被两条路径都算了，要扣掉重叠；再扣掉流失。例：基期 10000 + 新产品 1200 + 新客户 1000 − 交叉 400 − 流失 500 = 11300，目标 12000，还差 700。
- 目标缺口一直要说出来；不能承诺“必然达成”。

## 立项目

由关键路径形成关键项目：提取、归类、逻辑化、结构化、成果导向命名；管理水平高的企业用一级路径立项，一般企业用二级路径立项。导出关键项目列表的七列：项目编号、项目名称、战略关联 / 主题、项目目标、起止时间、关键节点、责任人。

坑：只分数（机械切数字）、把任务当目标、先填部门再画路径、路径过多平均用力。
