# 逻辑共识：简约战略逻辑化（S1-02 战略地图）

逻辑共识 = 知道战略“为什么”，从理解走向认可。

- 战略哲学：使命、愿景、价值观之间讲得通。
- 战略分析与决策：公司战略用“双二四”思考范式（图 2-5）提问，业务战略以客户与价值链为中心（图 2-6）提问。这两个只用来提问，不出成果。
- 战略内容：战略地图（图 2-8、2-9）按财务、客户、内部流程、学习与成长四个层面组织 3—5 年的战略目标，写清纵向因果和横向协同。它不是年度的战略解码地图。

引导顺序：先财务层“要什么结果”，再客户层“客户为什么选我们”，再内部流程“必须做好哪几件事”，最后学习与成长“人、系统、文化准备好了吗”。每一条都要能回答“它支撑上一层的哪一条”。

坑：只有“是什么”没有“为什么”；战略和策略混用、层级错位；关键争议被压下而不是记录。
