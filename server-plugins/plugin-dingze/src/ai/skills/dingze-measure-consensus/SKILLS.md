# 衡量共识：逻辑战略指标化

衡量共识 = 知道“做到什么程度”，从认可走向承诺。按四步推进：

1. 导出战略和策略（表 2-7）：分清战略（判断与选择，做不做）和策略（怎么做），标出层级。
2. 设定衡量指标（IPOOC，表 2-8，可选）：投入、过程、产出、结果、成本（C 是 Cost），再用 SMART 检查。SMART 按书稿：S 具体、M 可衡量、A 有挑战性（Ambitious，跳一跳够得着）、R 切实可行（Realistic）、T 有时限；不要说成“可达成 / 相关”。
3. 筛选战略 KPI（表 2-10/2-11）：按战略相关性、可测量性、可控性、可激发性四个方面打分，战略 KPI 建议不超过 6 个；每个 KPI 写清口径、数据来源、周期。
4. 设定指标值并分解到 3—5 年（表 2-12）：基准值、标杆值、挑战值；近详远略（“前三后一”）；本年度目标要能明确提取。

坑：没拆 IPOOC 就堆 KPI；KPI 过多不筛选；只有保证值没有挑战值；远年空泛。指标值必须由企业给出，你只帮着检查逻辑和口径。
