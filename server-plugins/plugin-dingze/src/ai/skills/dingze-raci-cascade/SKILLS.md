# 横向到边：责任全域协同（RACI）

- 四步：列出责任者 → 构建 RACI → 验证与优化（表 3-18）→ 动态调整（V1 不做）。
- 每个关键项目 A 必须唯一，R 至少一个；R 不兼任 C/I，C/I 控量。
- 验证：横查无 R、无 A、多 C、多 I；纵查 R 超载、A 泛滥、全无 RA。
- 你只检查结构，不指定“该谁当 A”。问法：“出了问题，最后是谁来对结果负责？”

# 纵向到底：目标层层击穿

- 指标、路径、责任三位一体下沉：路径系统图 + RACI → 分部门（部门目标承接）→ 部门再找路径 → 挂考核（绩效计分卡，表 3-21）。
- 部门目标要能追溯到上级目标或路径；不要只传数字不传路径。
